## 3. คณิตแบบ exact เมื่อมี √

### 3.1 ทำไมรูปเดียว a√b พอ
คำตอบทุกแบบในบทนี้เขียนเป็น **a√b ตัวเดียว** ได้ (a เป็นเศษส่วน, b เป็นจำนวนเต็มบวก squarefree) เพราะ:
- **ขนาด:** \|v\| = √(จำนวนตรรกยะ) = √(p/q) = √(pq)/q
- **เวกเตอร์หน่วย v/\|v\|:** ทุกองค์ประกอบเป็น (จำนวนตรรกยะ)/√N ซึ่งทำให้เป็น a√b ได้ โดยทุกช่องใช้ b เดียวกัน
- **cos θ:** cos θ = u·v / (\|u\|\|v\|) = ตรรกยะ / √(\|u\|²\|v\|²) เป็น a√b
- **u·v จาก \|u\|\|v\|cos θ:** ผลคูณของ a√b หลายตัวยังเป็น a√b
- **พื้นที่และปริมาตร:** พื้นที่ = \|u × v\| = √(จำนวนเต็ม) หรือครึ่งหนึ่งของมัน · ปริมาตรเป็นจำนวนเต็ม
- **ที่ไม่ปิด:** การบวก a√b + c√d เมื่อ b ≠ d (เช่น √2 + √5)
  - คำตอบถูกไม่เคยต้องใช้
  - มีแค่ candidate ของความเข้าใจผิดบางตัว (V11 \|u\| + \|v\|) ที่อาจเป็นแบบนี้
  - `applies` จึงตรวจก่อนว่ารวมเป็นตัวเดียวได้ ถ้าไม่ได้ ก็ไม่ใช้ข้อนั้นทดสอบ V11

**ทางเลือกที่ไม่เอา:**
1. เก็บเลขในรูป a + b√d ซับซ้อนกว่าที่บทนี้ต้องใช้
2. ถามแค่ \|v\|² เพื่อหนี √ ไม่ตรงกับที่ครูสอน
3. ทศนิยม ผิดหลักข้อ 1

### 3.2 `lib/core/surd.ts` (ใช้ร่วมได้ทุกหัวข้อ)
```ts
class Surd {            // value = coeff · √radicand
  coeff: Rational;      // 0 ⇒ radicand = 1
  radicand: number;     // จำนวนเต็มบวก squarefree, ≤ SURD_MAX_RADICAND
  static of(coeff: Rational, radicand?: number): Surd   // ดึงกำลังสองออกให้เอง: of(1, 18) = 3√2
  static sqrt(q: Rational): Surd                       // √(p/q) = √(pq)/q, q ≥ 0
  static rational(q: Rational): Surd
  mul(o) · div(o) · neg() · abs() · square(): Rational · sign()
  addSame(o): Surd | null      // บวกได้เฉพาะ radicand เดียวกัน ไม่งั้นคืน null (ไม่ throw)
  isRational(): boolean · equals(o) · compare(o)       // เทียบด้วย sign และ square ไม่ใช้ทศนิยม
  toString() // "3√2", "-√3/2", "3/2"  ·  toLatex() // 3\sqrt{2}, -\frac{\sqrt{3}}{2}
  static parse(text): Surd
}
```
- ใช้ `Rational` ข้างในทั้งหมด จึงตรวจ overflow แบบเดียวกัน (`safe`)
- รูปปกติ (normal form) มีแบบเดียว `equals` จึงแค่เทียบว่า coeff เท่ากันและ radicand เท่ากัน
- ไม่แตะ `rational.ts` เลย

### 3.3 การกรอกคำตอบ
- **ItemKind ใหม่ 2 แบบ:**
  - `surd`: ช่องเดียว มีปุ่ม √
  - `vector`: 2 หรือ 3 ช่องเรียงแนวตั้งในวงเล็บ แต่ละช่องรับ surd ได้
- **Answer ใหม่:** `{ kind: 'surd'; value: Surd }` และ `{ kind: 'vector'; value: Surd[] }`
  - เวกเตอร์ที่องค์ประกอบเป็นตรรกยะก็เก็บเป็น Surd ที่ radicand = 1
- **keypad:** ปุ่ม √ เป็นหลักที่ 5 โผล่เฉพาะเมื่อ item kind เป็น `surd` หรือ `vector`
  - ข้อเมทริกซ์เห็น keypad 4 หลักเดิมทุกปุ่ม
  - บน desktop กด `r` แทน √
- **`parseSurd` รับ:**
  - `3√2`, `-3√2`, `√2`, `3√2/2`, `-√3/2`, `1/√2`
  - `3/2√2` อ่านว่า (3/2)√2 กฎเดียว ไม่มีวงเล็บ เพราะ keypad ไม่มีปุ่มวงเล็บ
  - และจำนวนตรรกยะทุกแบบที่ `parseAnswer` รับอยู่แล้ว
- **รูปที่ยังไม่ทำให้อย่างต่ำนับว่าถูก**
  - เช่น √8 = 2√2 และ 1/√2 = √2/2 เหมือนที่ 2/4 นับว่าถูกในเมทริกซ์ (ค่าเท่ากัน)
  - FeedbackCard แสดงรูปอย่างต่ำให้ดูด้วย
  - **← ครูต้องตัดสิน** (§9 ข้อ 2)
- **มุม:** ข้อที่ถาม θ ตอบเป็นองศาด้วยช่อง `scalar` เดิม ("θ = □ องศา")

### 3.4 การจัดประเภทและ `validateItem`
- **`lib/core/classify.ts`:** `answersEqual` เพิ่ม case `surd` และ `vector` (เพิ่ม case ใน switch อย่างเดียว case เดิมไม่เปลี่ยน)
- **`lib/core/answerJson.ts`:** เพิ่ม case เก็บ/คืนค่า surd และ vector แบบเขียนชัดทุก kind
  - ตอนนี้มี `default: return answer` ซึ่งจะเก็บ Surd ผิดแบบเงียบๆ จึงเปลี่ยนเป็น switch ที่ compiler บังคับให้ครบ
- **slip ของเวกเตอร์:**
  - ผิดองค์ประกอบเดียว → `slip` พร้อมตำแหน่ง เหมือนผิดช่องเดียวของเมทริกซ์
  - ตอบจำนวนองค์ประกอบไม่ตรง (2 ช่องแทน 3) → `shape_error`
- **กฎข้อ 3 (ห่างจาก slip) ของเวกเตอร์:** diagnostic ต้องต่างจากคำตอบถูก ≥ 2 องค์ประกอบ
  - **ยกเว้น V20** (ลืมเครื่องหมายลบขององค์ประกอบกลางในผลคูณเชิงเวกเตอร์) ซึ่งโดยธรรมชาติผิดตัวเดียว
  - ยอมให้ V20 ผิดตัวเดียวได้ แต่ต้อง "กลับเครื่องหมายพอดี" และ |ค่า| ≥ 2
  - ใช้ state machine เดิม ซึ่งต้องเห็น ≥ 2 ครั้งก่อนเป็น `active` (SPEC §7.2)
  - **← ครูต้องเห็นด้วย** (§9 ข้อ 3)
- **คำตอบ surd ตัวเดียว:** ใช้กฎข้อ 3 ไม่ได้ เหมือน scalar ของเมทริกซ์
- **กฎข้อ 5–6 ของเวกเตอร์** อยู่ใน `lib/topics/vector/rules.ts`:
  - ช่วงตัวเลขตาม §2 และมุมเป็นมุมมาตรฐาน
  - ข้อขนานและข้อตั้งฉากต้องมีคำตอบเดียว
  - u × v ต้องตั้งฉากกับ u และ v (ตรวจซ้ำแบบ exact เหมือนตรวจ A·A⁻¹ = I)

## 4. ความเข้าใจผิด (ครูคณิตต้องตรวจทั้งส่วน)

- รูปแบบเดียวกับ MISCONCEPTIONS §3
- เวกเตอร์เขียนเป็น (a, b, c) · id ขึ้นต้นด้วย V จะได้ไม่ชนกับ M · ทุกตัวเป็น ★ ของหัวข้อนี้
- "ต่าง n ตัว" คือจำนวนองค์ประกอบที่ต่างจากคำตอบถูก (กฎข้อ 3)

   - แนะนำว่านับว่าถูกเหมือน 2/4 แล้วแสดงรูปอย่างต่ำให้ดู
   - ครูบางคนหักคะแนนถ้าไม่ทำตัวส่วนให้ไม่มีราก
3. **V20 (ลืมเครื่องหมายลบขององค์ประกอบกลางของ cross)** ยอมให้ผิดองค์ประกอบเดียวได้ไหม โดยต้องเห็น 2 ครั้งก่อนจะนับว่าเป็นความเข้าใจผิดจริง
4. **แบบทดสอบก่อน/หลังเรียนเวกเตอร์** จะใช้ในงานวิจัยไหม หรือแค่สร้างไว้ก่อน
5. **ElevenLabs:**
   - ตั้งบัญชีใหม่แล้วใส่ key เองใน `.env.local` (ห้ามส่ง key มาในแชท) แล้วบอกว่าใช้เครดิตได้ ~8,000
   - บัญชีฟรีห้ามใช้เชิงพาณิชย์และต้องให้เครดิต ElevenLabs ถ้าจะใช้ในงานประกวด อาจต้องใช้แผน Starter
6. **นักเรียนที่ทดลอง:** ที่สวนกุหลาบเป็น ม.4 ซึ่งยังไม่ได้เรียนเวกเตอร์ (บทนี้อยู่ ม.5)
   - จะให้ ม.4 ลองเวกเตอร์เป็นการเรียนล่วงหน้า หรือจะหานักเรียน ม.5 มาลอง
